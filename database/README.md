# QuizLab с XAMPP

1. Стартирай MySQL от XAMPP Control Panel.
2. За нова инсталация отвори phpMyAdmin и импортирай `database/quizlab.sql`.
3. От корена на проекта стартирай `dotnet run --project QuizLab`.

Базата `quizlab` съдържа куизите, профилите и историята на опитите. Връзката е в `QuizLab/appsettings.json`; при друга настройка използвай `ConnectionStrings__QuizLab` като променлива на средата.

Потребителите се създават от страницата „Регистрация“. Паролите се пазят като защитени хешове. След вход всеки завършен куиз се записва в `quiz_attempts`, а страницата „Постижения“ показва резултатите и общия напредък.

Въпросите се съхраняват и в `QuizLab/Data/quizzes.json`. След промени изпълни `python database/export_json.py`, след това импортирай отново SQL файла. Импортът обновява записи, но не чисти въпроси, премахнати от JSON.
